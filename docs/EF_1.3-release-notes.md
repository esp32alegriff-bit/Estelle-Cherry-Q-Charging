# EF_1.3

- EF_1.2 remains preserved as an untouched tagged release and APK.
- Added local charging History with 7-day, 30-day and All filters.
- Added editable electricity tariff (R/kWh) and charging-current (A) settings.
- Added live estimated kWh and Rand cost from elapsed charging time, configured current and 230 V.
- Each completed session permanently stores its own start/end time, duration, amps, tariff, estimated kWh and estimated cost on that phone.
- Added three local graph views: estimated energy by session, estimated cost trend, and charging-time split by current setting.
- Added on-device PDF report generation with WhatsApp sharing. No cloud/server is used.
- Preserved the existing relay address/token preferences, relay API contract, package ID and permanent APK signing key.
- Estimated energy/cost values are explicitly estimates until measured EV energy is integrated.
